# 🇺🇸 USA Election Game

A free, browser-based US Presidential Election simulator. Choose from historical election years, campaign across the United States, and use built-in modding editors to create custom scenarios. 

👉 **[Play Game](https://adlai-labs.github.io/usa-election-game)**

## ✨ Key Features
* Multiple historical election scenarios and candidates.
* Interactive electoral map to strategize state-by-state.
* Built-in modding tools: Scenario Editor (`editor.html`) and Event Editor (`eventeditor.html`).

## 📁 Project Structure
* `index.html` — Main game interface
* `editor.html` — Custom scenario editor
* `eventeditor.html` — Custom event editor
* `script/`, `data/`, `event/`, `maps/`, `audio/` — Core game assets and logic
